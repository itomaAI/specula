# FormalSolver 基本設計書

本設計書は、形式仕様検証モジュールの仕様書（`03_formal_solver.spec.md`）に規定された全状態空間探索および分割統治による自律検証を、全体基本設計書（`system_solution.design.md`）の規約に準拠して**どのように技術的・構造的に実現するか（How）**を定義する。

---

## 1. アーキテクチャと全体設計制約の継承

### 1.1 全体設計制約の適用
- **配置場所**: `specula/src/core/formal_solver.js`（Pure ESM, Target: ES2022+）。
- **Zero-I/O Core の遵守**: 本モジュールは直接ファイル読み込みや書き込みを行わず、メモリ上で形式仕様モデル（または Alloy AST）を受領し、決定論的検証レポート `SolverReport` を返す純粋な探索エンジンとして実装する。
- **依存方向の一方向性**: 外部環境（DOM/node）に依存せず、純粋計算機として完結する。

### 1.2 ソルバアーキテクチャ (Dual-Engine Architecture)
「LLM単体に論理計算をさせない」原則に基づき、数学的・決定論的な 2 重ソルバエンジン構成を採用する。

```
[FormalSpec (*.als)] ──➔ [AST Parser] ──➔ [Complexity Estimator]
                                                  │
                 ┌────────────────────────────────┴────────────────────────────────┐
                 ▼ (軽量 / ブラウザ内)                                             ▼ (重厚 / CLI・CI)
      [Engine A: Pure JS Matrix Solver]                               [Engine B: Kodkod / SAT Solver]
                 │                                                                 │
                 └────────────────────────────────┬────────────────────────────────┘
                                                  ▼
                                       [Compositional Slicer]
                                        (状態爆発時の自律分割統治)
                                                  │
                                                  ▼
                                       [SolverReport (決定論的出力)]
```

## 2. 決定論的検証アルゴリズム (Detailed Algorithms)

### 2.1 直積マトリクス探索 (State × Command Matrix Scanning)
- 状態集合 $S$ と操作述語集合 $C$ から、$|S| \times |C|$ の直積マトリクスを展開。
- 各セル $\langle s \in S, c \in C \rangle$ に対し、事前条件を満たす有効な遷移関数 $\delta(s, c)$ が存在するかを論理評価。
- 遷移が存在しないセルを「未定義遷移（Unhandled Transition）」として確実に検出。

### 2.2 グラフ探索によるデッドロックおよび到達不能性検出
- 状態を有向グラフのノード、遷移をエッジとする状態遷移グラフを構築。
- 初期状態 $s_0$ からの幅優先探索（BFS）を実行し、到達不能な孤立状態ノードを検出。
- 終端状態（Terminal）として明示的にタグ付けされていないにもかかわらず、出次数（out-degree）が 0 であるノードを「デッドロック（復帰不能）」として検出。

### 2.3 最小反例トレース導出 (BFS Counterexample Extraction)
- 安全プロパティ（`assert`）に対し、初期状態から違反状態に至るパスを幅優先探索で探索。
- 最初に見つかったパスを「最短反例トレース」として出力し、人間のデバッグ・理解を容易にする。

## 3. 分割統治による自律的自己解決 (Compositional Slicing)

全探索時の状態爆発を人間を介さずに自律解決するアルゴリズム：
1. **計算量見積もり**: 状態数と探索スコープから探索空間サイズを試算。閾値を超える場合、一括探索を停止。
2. **シナリオ単位のスライシング**:
   - 仕様全体を、独立したサブグラフ（シナリオ単位 / 境界づけられたコンテキスト単位）に自動分割。
3. **境界不変条件を用いた合成的検証**:
   - 各サブグラフを並行して検証し、コンテキスト間の越境イベントに対しては「大域不変条件」が破られないかをインターフェースレベルで検証。
   - すべてのサブグラフ検証を結合し、単一の統合 `SolverReport` として出力する。
